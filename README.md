# Nike Landing Page 🏀👟

A clean and modern **Nike Landing Page** built using **HTML** and **CSS**. This project demonstrates responsive web design principles and front-end layout skills for showcasing Nike products.

## 🚀 Features

- Modern and sleek Nike-themed UI
- Fully responsive for mobile, tablet, and desktop
- Clean and semantic HTML5 structure
- Custom CSS styling (no frameworks used)
- Smooth hover effects and transitions

## 📁 Technologies Used

- **HTML5** – Semantic layout and structure
- **CSS3** – Custom styling, Flexbox, responsive design
